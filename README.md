اے آئی کا دور

سب کچھ ہے، بس وقت نہیں،
یہ شکوہ ہر طرف عام ہے۔
موبائل میں دنیا سما گئی،
مگر گھر کا نام گم ہے۔

میٹنگ میں سب خاموش بیٹھے،
اسکرین ہی سب کی زبان ہے۔
جس دن بجلی چلی جائے،
پھر معلوم ہوتا ہے—
کمپنی چلتی نہیں،
چارجر ہی اصل سلطان ہے۔

اے آئی سے پوچھا میں نے،
"خوشی کہاں ملے گی؟"
بولا: "پہلے نوٹیفکیشن بند کرو،
پھر کھڑکی کھول کر خود دیکھو—
خوشی انٹرنیٹ سے باہر رہتی ہے!
